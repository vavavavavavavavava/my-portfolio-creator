# マイポートフォリオ作成ガイド

生成AIで経歴情報をJSONに整え、エディタで仕上げる手順です。生成AIを使わず、最初から各フォームへ入力することもできます。

## 作成手順

1. [マイポートフォリオエディタ](https://my-portfolio-creator.pages.dev/editor.html)を開く
2. 「プロンプトをコピー」を押す
3. コピーした文章をChatGPTなどの生成AIに貼り付け、自分の経歴情報を追記する
4. 生成されたJSONをすべてコピーする
5. エディタの「JSONを編集」に貼り付け、「変更を反映」を押す
6. 各タブで内容を確認・修正する
7. 「スライドプレビュー」を開き、「PDFで保存」を押す

印刷ダイアログでは出力先をPDFに設定してください。レイアウトが崩れる場合は、用紙をA4横向きにし、「背景のグラフィック」を有効にします。

## AIに渡す情報

文章の形式は自由です。分かる範囲で次の情報を含めると、修正の少ない下書きになります。

- 氏名、職種、所属
- 在籍期間、会社、役割
- プロジェクトの概要、担当内容、成果
- 使用した言語、フレームワーク、ツール
- 技術面・仕事面での強み
- 今後取り組みたい分野
- 資格

成果は「表示速度を30%改善」「問い合わせを月10件削減」のように、数値や変化を添えると伝わりやすくなります。機密情報や個人情報は、生成AIへ送る前に除いてください。

## エディタでの仕上げ

AIの出力には誤りや誇張が含まれることがあります。特に期間、数値、技術レベルを確認し、自分の言葉に直してください。

- プロジェクト画像は、ファイルまたは画像URLで追加できます
- `**重要な成果**` のように囲むと、プレビューで赤い太字になります
- 作業途中のデータは「JSONを編集」画面からダウンロードできます
- AIに修正を頼む場合は、現在のJSONと変更点を一緒に渡します

修正依頼の例：

```text
以下のポートフォリオJSONを修正してください。

- ○○プロジェクトの成果を簡潔にする
- Dockerを「実務経験」に変更する
- 強みに「チーム内の技術共有」を追加する

【現在のJSON】
（エディタから取得したJSON）
```

## 困ったとき

- **JSONを読み込めない**: コードブロックの記号を除き、`{` から `}` までのJSONだけを貼り付けます
- **画像が表示されない**: URLがブラウザから参照できるか、または画像ファイルを選び直したか確認します
- **内容が収まらない**: 長い説明を要点と成果に絞り、プレビューで各ページのバランスを確認します
